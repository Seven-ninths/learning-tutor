# Learning Tutor · 中文学习 Skill

在 Codex 中按你的基础带学。它从学习资料提炼路线，用完整例子解释知识点，并在每个板块后逐题口试。学习笔记、主题知识图谱和口试进度都保存在本地。

## 开始使用

1. 克隆此仓库，将仓库根目录选为 Codex 工作目录。
2. 确认本机可以运行 Node.js 24 或更新版本。记录工具使用 Node.js 内置模块，无需安装 npm 依赖。
3. 在 Codex 输入 `$learning-tutor 我想学线性代数，先帮我摸底。` 也可以附上自己的教材、讲义或链接。

答疑后，在 `学习工作区/主题/` 查看简明 Markdown 学习笔记，或用浏览器打开 `学习工作区/知识图谱.html`。网页可离线查看，可切换主题，点击知识点在右侧阅读完整例子和资料出处。新答疑保存后，刷新页面即可看到更新。

续学时可以输入 `$learning-tutor 继续学线性代数。` 学习资料和记录保存在 `学习工作区/`，该目录由 Git 忽略。
